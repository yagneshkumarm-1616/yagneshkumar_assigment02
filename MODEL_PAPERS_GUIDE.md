## 📊 Scoring Guide

### Expected Score Calculation:
```
Score = (Correct Answers × 1) - (Wrong Answers × 0.25)
```

### Example:
```
Correct: 60 questions = 60 marks
Wrong: 10 questions = 2.5 marks (negative)
Unattempted: 5 questions = 0 marks

Total Score = 60 - 2.5 = 57.5 / 75 (76.67%)
```
